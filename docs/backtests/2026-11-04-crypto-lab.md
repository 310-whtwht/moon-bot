# 仮想通貨（メジャーとマイナー）をラボで検査した

- 日付: 2026-11-04
- 目的: ボットを仮想通貨に対応させる前に、利益の源がありそうかを過去データで確かめる。合格が出たときだけ、取引先への接続を作る
- データ: GMO コインのレバレッジ取引の公開の1時間足（約定値。BID・ASK はない）。取得は [research/crypto/fetch.py](../../research/crypto/fetch.py)
  - メジャー: BTC_JPY・ETH_JPY（2021-04〜2026-11）
  - マイナー: DOT_JPY・ATOM_JPY（2024-04〜2026-11）。取引のない時間の足が抜けている（DOT 約25%、ATOM 約45%）
- 計算: ボットのバックテストそのもの。足をファイルから読む `-candles-in` と、レバレッジの `-leverage`（2倍）を足した
- コスト（1回の約定ごと、保守的）: 2026-11-04 のスプレッドの半分の2倍＋手数料、最低 0.05%
  - BTC 0.05%、ETH 0.06%、DOT 0.71%、ATOM 0.47%（板のスプレッド BTC 0.013%、ETH 0.058%、DOT 0.678%、ATOM 0.445%）
  - 建玉の持ち越しの費用は入れていない（未確認）

r1 は大きさの基準が厳しく、取引が2〜29回で判定できなかった。基準を損益を見ずに回数だけで決め直した r2 の結果:

## 読み取れること

- **マイナー通貨はコストで負ける。** スプレッドが 0.4〜0.7% あり、1回の往復で 1% 前後かかる。コストを引く前でも、はっきりした効果はなかった
- **メジャー通貨は、ETF の基準の時刻のあとの戻りだけに手がかりがある。** BTC はコストを引く前で 1回 +0.073%、t 2.88（必要な t は 3.14 で届かない）。往復 0.1% と見たコストより小さいので不合格。実際の BTC のスプレッドは 0.013% と狭いので、コストの見積もりしだいで結果が変わる
- 次に確かめるなら、BTC の 16:00（NY）の前後のスプレッドを実測すること。過去のスプレッドは公開されていないので、Paper か板の記録で集める必要がある
- 冬時間の入り（21:00 UTC）は日本時間 6:00 で、建玉の持ち越しの費用がかかる時刻の近く。条件は未確認
