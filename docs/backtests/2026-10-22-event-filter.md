# 経済指標の発表で見送るフィルターの評価

- 日付: 2026-10-22
- 予定表: [research/events/us_jp_events.csv](../../research/events/us_jp_events.csv)（2023-10〜2026-10、122件）
  - 米雇用統計（us_nfp）・米CPI（us_cpi）: 米国東部時間 8:30。BLS のアーカイブのファイル名から発表日を取った（2025年10月分は政府閉鎖で未発表）
  - FOMC（fomc）: 会合の最終日の 14:00（米国東部時間）。FRB の会合予定表から取った
  - 日銀の金融政策決定会合（boj）: 最終日の 12:00 JST を代表値にした（実際は 11時台〜13時台でばらつく）。日銀の会合予定表から取った
- 予定表の確かめ: 発表の5分足の値動きを、発表が無い日の同じ時刻の5分足と比べた（USD/JPY）。雇用統計は中央値 13.7倍、CPI 9.7倍、FOMC 10.6倍で、日付と時刻は合っている。日銀は 2.2倍（発表時刻がずれるため）
- やり方: [research/events/event_filter.py](../../research/events/event_filter.py)。各ルールの取引から次のものを見送り、ランダムに同じ数を見送った場合（1000回）と比べた
  - near: 入る30分前から、入って4時間後までに発表がある取引
  - day: 発表がある取引日（6:00 JST 区切り）の取引すべて
  - どちらも、入る時点で分かる情報（前もって公表される予定）だけを使う
- 取引は、[2026-10-22-crowd-psychology.md](2026-10-22-crowd-psychology.md) と [2026-10-22-ml-meta-filter.md](2026-10-22-ml-meta-filter.md) と同じ設定で出したもの

### 仲値後の売り・発表日を見送った場合の内訳

| | 全部 | 見送った取引 | 残した取引の PF |
|---|---|---|---|
| 前半（2023-10-31〜2025-04 下旬） | 106回 +647円 PF 1.95 | 23回 −112円 | 2.61 |
| 後半（2025-04 下旬〜2026-10-21） | 106回 +230円 PF 1.33 | 19回 −81円 | 1.58 |

発表の種類別（同じ日に重なる取引は両方に数える）: 雇用統計の日 17回 −146円、CPI の日 10回 −32円、FOMC の日 4回 −61円、日銀の日 12回 −1円。

## 読み取れること

- **仲値後の売りは、米国の発表がある日に負けていた。** 前半・後半とも、発表日の取引はマイナスで、見送ると PF が上がる（1.95 → 2.61、1.33 → 1.58）。ランダムに同じ数を見送っても、ここまで良くはならなかった。日銀の日は損益ゼロで、効いているのは米国の発表（特に雇用統計）の日。
  - 考えられる理由（仮説・未検証）: 夜に大きな発表を控えた日は、東京の朝のドルの売り買いが発表待ちになり、仲値のあとの戻りが起きにくい。
- **ブレイク系のルール（東京レンジ・トレンドライン）は、発表日の方が成績が良い。** 値動きが大きい日ほど、抜けが伸びるため。見送ると成績が下がるので、使わない。
- 「入った直後に発表がある取引」（near）を見送っても、どのルールでも差は出なかった。

## 注意

- 4つのルール × 2つの見送り方を試し、その中で効いたのは1つだけ。たくさん試したぶん、偶然が混ざりやすい。
- 見送った取引は 42回と少ない。
- 予定表は米国の3指標と日銀だけ。英国の指標（GBP/JPY に効くもの）や、要人の発言は入っていない。
- 実際に使うには、これから先の予定表を前もって用意し、更新し続ける必要がある。
