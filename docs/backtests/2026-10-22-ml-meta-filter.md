# 機械学習のフィルター（メタラベリング）の評価

- 日付: 2026-10-22
- やり方: [research/ml/meta_filter.py](../../research/ml/meta_filter.py)
  - ルールが出した取引ごとに、入る直前までの足だけから特徴量を作り、「勝つか負けるか」を学習させる
  - 勝つ見込みが低い取引を見送り、残した取引の成績を、フィルター無し・ランダムに同じ数を見送った場合と比べる
  - 3か月ごとに区切り、各区間は「それより前の取引だけ」で学習したモデルで判定する（ウォークフォワード）。見送る割合（0〜50%）も、学習側の期間の中だけで決める
  - 学習に使う取引が 150回に満たない区間は判定しない
- 特徴量（すべて取引の向きに合わせて符号をそろえる）: 時刻・曜日、ATR の大きさ（価格比・ATR100 比）、直近12本・48本の値動き、EMA50 との距離と傾き、RSI、直近48本の中での位置、その日の値幅、シグナル足の実体、スプレッド、直前の取引と直近5回の勝ち負け
- モデル: ロジスティック回帰、勾配ブースティング（scikit-learn）
- 取引とローソク足は `bot backtest -json -candles-out` で書き出した（成行・100通貨・初期資金 30,000円）

## 結果（判定した期間の合計）

| ルール | モデル | AUC | フィルター無し | 通した取引 | ランダムに同じ数を見送った場合 |
|---|---|---|---|---|---|
| 東京レンジ USD/JPY 5分足（range_end 960・buffer 0.3） | ロジスティック回帰 | 0.508 | 368回 +1,622円 PF 1.23 | 279回 +804円 PF 1.15 | +1,168円 |
| | 勾配ブースティング | 0.496 | 同上 | 364回 +1,689円 PF 1.24 | +1,581円 |
| 東京レンジ GBP/JPY 15分足（range_end 840・buffer 0.3） | ロジスティック回帰 | 0.528 | 242回 +632円 PF 1.12 | 152回 +771円 PF 1.24 | +832円 |
| | 勾配ブースティング | 0.457 | 同上 | 172回 +660円 PF 1.17 | +426円 |
| トレンドライン抜け USD/JPY 1時間足（pivot 3・stop_atr 1.5） | ロジスティック回帰 | 0.551 | 831回 +414円 PF 1.02 | 670回 +969円 PF 1.07 | +394円 |
| | 勾配ブースティング | 0.521 | 同上 | 532回 +117円 PF 1.01 | +84円 |
| 仲値後の売り USD/JPY 5分足 | 両方 | 0.50〜0.56 | 58回 +32円 PF 1.08 | ほぼ見送らず | — |

AUC は、勝ちと負けをどれだけ見分けられたか（0.5 = 当てずっぽう、1.0 = 完全）。

## 読み取れること

- **どのルールでも、勝ち負けをほとんど見分けられなかった。** AUC は 0.46〜0.55 で、当てずっぽうに近い。
- 東京レンジ USD/JPY では、フィルターを入れると、ランダムに見送るより悪くなった。GBP/JPY は、2つのモデルで結果が逆になり、一貫しない。
- トレンドライン抜け（ロジスティック回帰）だけが、ランダムより +575円よく、AUC も 0.551 で最も高かった。ただし、10区間のうち改善は6区間で、PF は 1.02 → 1.07 と小さい。採用できる差ではない。
- 仲値後の売りは、取引が少なすぎて学習できない（判定できたのは2026年の58回だけ）。
- 一般的なテクニカルの特徴量は、ルールのシグナルがすでに使っている情報とほぼ重なる。そのため、上乗せが出にくいと考えられる。

## 注意

- 見送った取引のあとに、別の取引が入る可能性は無視している。東京レンジと仲値は1日1回までなので、影響は小さい。トレンドラインでは近似になる。
- 見送る割合は、学習側の予測の分位で決めている。そのため、判定する期間で実際に見送る割合は、設定とずれることがある（例: 10%の設定で37%を見送った区間がある）。
- 特徴量とモデルは1通りずつしか試していない。調整を重ねると、見かけだけ良くなる危険が増える。
