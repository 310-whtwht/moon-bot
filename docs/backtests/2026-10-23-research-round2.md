# 過去データでの検証（第2弾）— 仲値後の売りの改良、滑りへの強さ、ほかの銘柄での確認

- 日付: 2026-10-23
- 方針: Paper で1回ずつ確かめるのは遅いので、過去データで詰める。次の3点を厳しめに見る
  1. 前半・後半の両方で黒字か（期間を分けても同じ結果になるか）
  2. 約定が不利になっても残るか（滑り。`bot backtest -slippage`）
  3. USD/JPY で決めた設定が、ほかの銘柄でもそのまま通用するか（設定を変えずに当てる）
- 条件: 100通貨、初期資金 30,000円、成行（買いは ASK・売りは BID、次の足の始値で約定）、手数料 0.002%
- 期間: USD/JPY は 2023-10-28〜2026-10-22。前半は 2025-03-31 まで、後半は 2025-04-01 から

## 1. 時間帯のくせの洗い出し（USD/JPY 5分足）

[research/seasonality/scan.py](../../research/seasonality/scan.py) で、「曜日 × 開始時刻（30分刻み）」「ゴトー日かどうか × 開始時刻」「月の最終営業日かどうか × 開始時刻」ごとに、60分・120分持ったときの値動き（中値）を集めた。前半・後半で同じ向き、スプレッドの2倍を超える、t 値 3 以上、の3つを満たしたものは次の2つだけだった。

| くせ | 平均（60分） | 実際の売値・買値で確かめた結果 |
|---|---|---|
| ゴトー日の 9:30 からの下げ | −4.3銭（前半 −5.3 / 後半 −3.3） | 仲値後の売りとして採用済み（下で改良） |
| 木曜 5:30 からの下げ（米国の水曜の取引終了の直後） | −4.5銭 | **不採用**。この時間帯はスプレッドが大きく開き、[weekday_window.star](../../strategies/research/weekday_window.star) で確かめると16通り中2通りしか両方で黒字にならない |

ゴトー日の朝の値動きを5分ごとに平均すると、下げは **9:55〜10:00 の5分間に集中** していた（前半・後半とも約3銭）。後半の期間では、10:00 以降はほぼ横ばい。

## 2. 仲値後の売りの改良（v2）

### 決済の時刻

決済を 11:30 から早めると良くなった。決済時刻 × 損切り幅の21通りは、すべて前半・後半とも黒字。

| 決済 | 前半 PF | 後半 PF |
|---|---|---|
| 10:00 | 1.85 | 2.48 |
| 10:10 | 2.76 | 1.67 |
| **10:20** | **2.83** | **2.22** |
| 10:30 | 2.22 | 1.44 |
| 11:30（今の Paper） | 2.00 | 1.32 |

（損切り ATR×3、滑りなし）

### 見送る日

毎営業日で同じ売り（10:20 決済）をして、日の種類で分けた。

| 日の種類 | 回数 | 損益 | PF（全体 / 前半 / 後半） |
|---|---|---|---|
| 毎営業日 | 773 | +436円 | 1.12 / 1.17 / 1.06 |
| ゴトー日 | 212 | +993円 | 2.49 / 2.57 / 2.41 |
| 通常日 | 561 | −557円 | 0.81 / 0.87 / 0.73 |
| ゴトー日・祝日 | 11 | −6円 | 0.87 |
| ゴトー日・米国の指標日 | 31 | −29円 | 0.82 / 1.26 / 0.45 |
| **ゴトー日・祝日でも米国の指標日でもない** | **173** | **+1,014円** | **3.14 / 3.16 / 3.11** |

- 祝日は仲値の公示がない。銀行の休業日（12/31・1/2・1/3）も見送る
- 米国の指標日は、雇用統計・CPI・FOMC がある取引日（6:00 JST 区切り）。前回の評価（[2026-10-22-event-filter.md](2026-10-22-event-filter.md)）と同じ結果
- ゴトー日の種類別（5・10・15・20・25日・月末）でも、曜日別でも、すべて黒字

### 滑りへの強さ

約定ごとに不利にした値（往復でその2倍）。全期間、損切り ATR×3。

| 滑り | 10:20 決済の PF | 11:30 決済の PF |
|---|---|---|
| なし | 2.49 | 1.63 |
| 0.3銭 | 2.21 | 1.52 |
| 0.5銭 | 2.04 | 1.45 |
| 1銭 | 1.68 | 1.28 |

v2（見送りあり）に滑り 0.5銭を入れても、決済時刻（10:05〜10:40）× 損切り幅（ATR×2・3・5）の21通りすべてが前半・後半とも黒字。10:20・ATR×3 で前半・後半とも PF 2.58。

### 1年の見込み（v2、滑り 0.5銭、100通貨）

170回の取引を並べ替えて、1年分（約58回）を1万回作った。

- 1年の損益: 5%点 +115円 / 中央値 +288円 / 95%点 +463円。赤字の年になる確率 0.2%
- 1年の中の最大の落ち込み: 中央値 40円 / 95%点 78円 / 99%点 104円
- 最大の連敗: 中央値 4回 / 95%点 6回

### トレンドラインの設定の広さ（滑り 0.5銭）

pivot（7・10・14・20）× 損切り（ATR×1.5・2・3）× ライン の有効期間（100・150・300本）の36通りのうち、34通りが前半・後半とも黒字。さらに大きい pivot では次のとおり。

| pivot | 前半 PF | 後半 PF |
|---|---|---|
| 14 | 1.19〜1.21 | 1.88〜2.11 |
| 20 | 1.53〜1.63 | 1.68〜1.77 |
| 30 | 1.06〜1.48 | 1.31〜1.55 |
| 40 | 0.70〜1.26 | 0.62〜0.71 |

pivot 10〜20 が安定した範囲。40 では崩れる。

## 6. ほかの銘柄での確認（設定は USD/JPY で決めたまま、滑り 0.5銭込み）

GBP/JPY・EUR/JPY・AUD/JPY を 2023-10-28 から取り込み、USD/JPY と同じ期間・同じ前半後半の区切りで確かめた。どの銘柄のデータも、設定を選ぶのには使っていない。

### 仲値後の売り v2（5分足）

| 銘柄 | 見送り | 前半 | 後半 |
|---|---|---|---|
| USD/JPY | あり | PF 2.58（80回） | PF 2.58（90回） |
| GBP/JPY | なし | PF 2.46（101回） | PF 1.36（112回） |
| | **あり** | **PF 2.94（80回 +499円）** | **PF 1.91（91回 +322円）** |
| EUR/JPY | なし | PF 2.82（101回） | PF 1.36（112回） |
| | **あり** | **PF 3.46（80回 +496円）** | **PF 1.95（91回 +285円）** |
| AUD/JPY | なし | PF 1.52 | PF 0.91 |
| | あり | PF 1.67（+151円） | PF 1.16（+49円） |

円を売る側の流れなので、ほかの円の通貨ペアにも同じ形で出た。見送り（祝日・米国の指標日）は、どの銘柄でも前半・後半とも成績を上げた。AUD/JPY は弱い。

### トレンドライン抜け（1時間足、損切り ATR×2）

| 銘柄 | pivot 10・14・20 × 有効期間 150・300 の6通りで、前半・後半とも黒字 | PF の範囲（前半 / 後半） |
|---|---|---|
| USD/JPY | 6 / 6 | 1.20〜1.65 / 1.08〜1.92 |
| GBP/JPY | **0 / 6** | 0.54〜1.00 / 0.48〜1.04 |
| EUR/JPY | **0 / 6** | 0.59〜0.86 / 0.64〜0.88 |
| AUD/JPY | **0 / 6** | 0.57〜0.74 / 0.96〜1.15 |

**USD/JPY でしか勝てていない。** USD/JPY での好成績は、この3年の USD/JPY の値動き（大きなトレンドが続いた）に合っていただけの可能性が高い。

### 東京レンジのブレイク（5分足、range_end 960・buffer 0.3・レンジの反対側で損切り）

| 銘柄 | 前半 | 後半 |
|---|---|---|
| GBP/JPY | PF 0.94 | PF 1.00 |
| EUR/JPY | PF 0.99 | PF 0.88 |
| AUD/JPY | PF 0.83 | PF 0.87 |

ほかの銘柄では通用しない（滑りなしでも GBP/JPY は PF 0.88〜1.04）。

## 7. まとめ

| ルール | USD/JPY | ほかの銘柄 | 滑り | 判断 |
|---|---|---|---|---|
| 仲値後の売り v2 | ◯ | ◯（GBP・EUR）、△（AUD） | 強い | **本命**。理由（仲値に向けたドル買いの反動）と、銘柄をまたいだ再現がそろっている |
| トレンドライン抜け | ◯ | × | 強い | USD/JPY だけ。この3年の USD/JPY に合っていただけの疑いが強い |
| 東京レンジのブレイク | △ | × | 弱い | 外す |

## 注意

- 仲値後の売りの「見送る日」は、同じ期間のデータを見て決めた。祝日は理由がはっきりしているが、米国の指標日は、たくさん試した中で効いたものでもある
- 1回の利益は約5円（100通貨）と小さい。実際のスプレッドや約定の遅れが、バックテストより大きいと崩れる。Paper の 10/23 の1回目は、9:55:22 に約定した（バックテストは 9:55:00 の始値）
- GMO の過去データは 2023-10-28 からしかない。どのルールも約3年での評価
