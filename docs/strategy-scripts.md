# 売買ルールをスクリプトで書く

売買ルールを、プログラム本体を変えずに画面から書き換えられます。書いたルールは、バックテスト・Paper・本番で同じように動きます。

- 言語は **Starlark** です。Python によく似た書き方ができます。
- ファイルの読み書き、通信、外部ライブラリの読み込みはできません（安全のためです）。
- スクリプトが決めるのは「買う・売る・決済する・何もしない」と損切り価格だけです。数量、リスク上限、Kill Switch、発注は、これまでどおり bot が管理します。

## 1. いちばん小さな例

```python
def on_bar(bar, pos):
    return hold()
```

`on_bar` は、足が確定するたびに1回呼ばれます。上の例は、いつも「何もしない」を返します。

## 2. 作って動かすまでの手順

1. 画面上部のメニューで「戦略管理」を開きます。
2. ルールを入れたい戦略を開きます（新しく作る場合は「New Strategy」を押して作ります）。
3. 「New Version」を押します。
4. 「戦略の種類」で「スクリプト（script）」を選びます。
5. スクリプトの欄に、EMA クロスのサンプルが入っています。これを書き換えます。
6. 「スクリプトを確認」を押します。
   - 文法に誤りがあると、赤い枠に行番号つきでエラーが出ます。直してもう一度押します。
   - 問題がなければ「問題ありません」と出て、パラメータの入力欄が現れます。
7. パラメータの値を必要に応じて変えます。
8. 「バージョン名」を入力します（例: `1.0.0`）。
9. まだ試していないルールは、「このバージョンを有効にする」を**オフ**にします。
10. 「作成」を押します。
11. 戦略の画面で「Backtest」を押し、作ったバージョンを選んでバックテストを実行します。
12. 結果に納得できたら、同じ内容で「有効にする」をオンにしたバージョンを作ります。割り当てが動いていれば、建玉を持っていないタイミングで新しいルールに切り替わります。

作成したバージョンは書き換えられません。直すときは、新しいバージョンを作ります。どの注文がどのバージョンのルールで出たかは、記録に残ります。

## 3. `on_bar` が受け取るもの

### `bar`（いま確定した足）

| 名前 | 内容 |
|---|---|
| `bar.open` / `bar.high` / `bar.low` / `bar.close` | 始値・高値・安値・終値（BID） |
| `bar.time` | 足の始まりの時刻（Unix 秒） |
| `bar.hour` / `bar.minute` | 足の始まりの時・分（日本時間） |
| `bar.weekday` | 曜日（日本時間。月曜 = 0 〜 日曜 = 6） |

### `pos`（いま持っている建玉）

建玉がなければ `None` です。あれば次の値を持ちます。

| 名前 | 内容 |
|---|---|
| `pos.side` | `"long"`（買い）または `"short"`（売り） |
| `pos.entry` | 建値 |

## 4. 返す値

| 書き方 | 意味 |
|---|---|
| `buy(stop=価格, reason="メモ")` | 買いで入ります。売りを持っていれば、決済してから入ります |
| `sell(stop=価格, reason="メモ")` | 売りで入ります。買いを持っていれば、決済してから入ります |
| `exit(reason="メモ")` | 建玉を決済します |
| `hold()` または `None` | 何もしません |

- `stop` は損切りの**価格**です（幅ではありません）。必ず指定します。
- 発注は**次の足の始まり**で行われます。損切りは、実際の約定価格から同じ幅になるように置き直されます。
- `reason` は省略できます。注文の記録に残ります。

## 5. 使える関数

### 指標

どれも `関数(期間, ago=何本前)` の形です。`ago` を省くと、いま確定した足の値になります。足が足りず計算できないときは `None` を返します。

| 関数 | 内容 |
|---|---|
| `ema(n)` | 終値の指数移動平均 |
| `sma(n)` | 終値の単純移動平均 |
| `rsi(n)` | RSI（0〜100） |
| `atr(n)` | ATR（値動きの大きさ） |
| `highest(n)` | 直近 n 本の高値の最大 |
| `lowest(n)` | 直近 n 本の安値の最小 |

### 過去の価格

| 関数 | 内容 |
|---|---|
| `close(ago=1)` | 1本前の終値。`open` / `high` / `low` も同じ形です |
| `bars()` | これまでに受け取った足の本数 |

### そのほか

| 名前 | 内容 |
|---|---|
| `p.名前` | パラメータの値（次の節） |
| `state` | 足をまたいで値を覚えておく入れ物です。`state["count"] = state.get("count", 0) + 1` のように使います。bot を再起動すると空に戻ります（起動時に過去500本を流し直すので、その分は再現されます） |
| `explain("メモ")` | この足の判定に添えるメモです。ログと、チャート画面の「足ごとの判定」に出ます |
| `num(x, digits=3)` | 数値を文字にします（小数の桁数を指定）。`"%.3f" % x` の書き方は使えません |
| `fail("理由")` | スクリプトをエラーで止めます |

## 6. パラメータ

スクリプトの先頭に `PARAMS` を書くと、その値をバージョンごとに画面から変えられます。値は数値だけです。

```python
PARAMS = {"period": 20, "stop_atr": 2.0}

def on_bar(bar, pos):
    top = highest(p.period, ago=1)   # p.period で読みます
    ...
```

## 7. 例: 高値・安値のブレイクアウト

直近20本の高値を終値で上抜けたら買い、安値を下抜けたら売ります。日本時間の9時〜翌2時だけ新規に入ります。

```python
PARAMS = {"period": 20, "atr_period": 14, "stop_atr": 1.5}

def on_bar(bar, pos):
    top = highest(p.period, ago=1)     # いまの足を含めない、直近の高値
    bottom = lowest(p.period, ago=1)
    a = atr(p.atr_period)
    if None in (top, bottom, a):
        return hold()

    explain("top=" + num(top) + " bottom=" + num(bottom))

    active = bar.hour >= 9 or bar.hour < 2
    if not active:
        return hold()

    if bar.close > top and (pos == None or pos.side == "short"):
        return buy(stop=bar.close - p.stop_atr * a, reason="breakout up")
    if bar.close < bottom and (pos == None or pos.side == "long"):
        return sell(stop=bar.close + p.stop_atr * a, reason="breakout down")
    return hold()
```

## 8. エラーが起きたとき

| いつ | どうなるか |
|---|---|
| 「スクリプトを確認」や作成のとき | 文法の誤りなどを、行番号つきで画面に表示します。保存はされません |
| バックテストの途中 | そのバックテストは失敗になり、理由が表示されます |
| Paper・本番で動いている途中 | そのルールは**それ以降ずっと「何もしない」**になります。Slack に「エラー」が1回届きます。保有中の建玉の損切りは動き続けます。直したバージョンを有効にすると、建玉がないタイミングで切り替わります |

終わらないループを書いた場合も、一定の計算量で打ち切ってエラーにします。bot 全体は止まりません。

## 9. 手元のファイルでバックテストする（コマンド）

スクリプトをファイルに保存して、画面を使わずに試すこともできます。先に、その銘柄と足のデータを取り込んでおきます。

```bash
docker compose run --rm bot backfill -symbol GBP_JPY -interval 15m -from 2025-01-01
```

```bash
docker compose run --rm -v "$PWD/my_rule.star:/my_rule.star" bot backtest -script /my_rule.star -symbol GBP_JPY -interval 15m -from 2025-01-01
```

`-param 名前=値` で値を変えたり、`-sweep 名前=値1,値2` で複数の値をまとめて比べたりできます。

## 10. 注意点

- 判定は**確定した足**でだけ行われます。足の途中の値動きには反応しません（損切りだけは、bot が実際のレートで常に見ています）。
- 見えるのは、その割り当ての銘柄・足だけです。ほかの銘柄や、上位の足を同時に見ることはできません。
- 利益確定の価格を別に置くことはできません。`on_bar` の中で条件を書き、`exit()` を返してください（判定は足の確定時になります）。
- 数量はスクリプトでは決められません。割り当ての設定で決めます。
